# ProjectMind Frontend

Frontend inicial con React + Vite.

## Instalación

```bash
npm install
```

Copiar:

```text
.env.example -> .env
```

Ejecutar:

```bash
npm run dev
```

Abrir:

`http://localhost:5173`

La pantalla consulta el endpoint:

`GET /api/v1/health`

para verificar la comunicación con FastAPI.
